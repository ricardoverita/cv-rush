# CV Rush

*Read this in [Español](README.es.md).*

> **Status: design phase.** No playable code yet. The full README (setup, contributing, license) arrives with the repository foundations.

**CV Rush** (provisional name) is an open-source 2D browser game about the hiring process, and the entry point to a developer network. Grab your CV and race through recruiters, an ATS machine and interviews to deliver it at the company. Every run builds your developer profile: XP, levels, history and rankings.

- 🏃 2–5 minute runs, playable on phones and desktops
- 🧑‍💻 **Compete as who you are:** pick your seniority, role and stack. You get a job built for you and compete against comparable profiles (e.g. Fullstack · Senior+)
- 📈 **Persistent progress:** score, XP, CV Rush Level, history and gameplay stats, kept even before accounts exist
- 🎯 **Ranked runs** with category rankings and Daily Champions, and unlimited **practice runs**
- 🛡️ Server-authoritative gameplay: questions are served just in time, and the server computes every result
- 🌍 Spanish and English from day one
- 🤝 Built to be contributable: add questions, technologies and translations without touching game code
