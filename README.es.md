**CV Rush** (nombre provisional) es un juego web 2D open source sobre el proceso de selección, y la puerta de entrada a una red de developers. Toma tu CV y atraviesa recruiters, una máquina ATS y entrevistas para entregarlo en la empresa. Cada partida construye tu perfil de developer: XP, niveles, historial y rankings.

- 🏃 Partidas de 2 a 5 minutos, jugables en móvil y escritorio
- 🧑‍💻 **Compite como quien eres:** elige tu seniority, rol y stack. Recibes una oferta hecha para ti y compites contra perfiles comparables (p. ej. Fullstack · Senior+)
- 📈 **Progreso persistente:** score, XP, CV Rush Level, historial y estadísticas de juego, incluso antes de que existan cuentas
- 🎯 **Partidas rankeadas** con rankings por categoría y Daily Champions, y **partidas de práctica** ilimitadas
- 🛡️ Juego server-authoritative: las preguntas llegan justo a tiempo y el servidor calcula cada resultado
- 🌍 Español e inglés desde el primer día
- 🤝 Pensado para contribuir: añade preguntas, tecnologías y traducciones sin tocar el código del juego
