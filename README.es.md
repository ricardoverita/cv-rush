# CV Rush

*Read this in [English](README.md).*

> **Estado: fase de diseño.** Todavía no hay código jugable. El README completo (instalación, cómo contribuir, licencia) llegará con la base del repositorio.

**CV Rush** (nombre provisional) es un juego web 2D, competitivo y open source, sobre el proceso de selección. Encontraste una oferta que te interesa: toma tu CV y atraviesa recruiters, una máquina ATS y entrevistas para entregarlo en la empresa antes que el resto de candidatos.

- 🏃 Partidas de 2 a 5 minutos, jugables en móvil y escritorio
- 🧑‍💻 **Compite como quien eres:** elige tu seniority, rol y stack. Recibes una oferta hecha para ti y compites contra perfiles comparables (p. ej. Fullstack · Senior+)
- 🎯 Un modo **Casual** para practicar y un **Daily Challenge** rankeado, con Daily Champions y Top 7 semanal por categoría
- 🛡️ Juego server-authoritative: las preguntas llegan justo a tiempo y el servidor calcula cada resultado
- 🌍 Español e inglés desde el primer día
- 🤝 Pensado para contribuir: añade preguntas, tecnologías y traducciones sin tocar el código del juego
